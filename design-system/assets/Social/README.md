# Social

These are filled profile marks for the hero and footer. The files are single-ink `ink-tertiary` (#8f857d). In use they sit in `ink-secondary` and turn `ink-primary` on hover. Keep them monochrome.

- `github.svg`: GitHub (AlyIbrahim1).
- `linkedin.svg`: LinkedIn.
- `mail.svg`: email, outlined to match the stroke set.
