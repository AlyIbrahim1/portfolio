# Icons

These are the site's UI strokes, drawn on a 24×24 grid with a 1.6 stroke and round caps and joins. The files here are single-ink in `ink-tertiary` (#8f857d) for preview. In code, use `Aly.Icon`, which inherits `currentColor`.

- `arrow-up-right.svg`: leaves the page (external links, project cards, All Projects).
- `arrow-right.svg`: moves within the page (hero CTA, mobile menu rows).
- `arrow-up.svg`: back to top.
- `close.svg`: closes a dialog or menu.
- `send.svg`: the contact form's Send button.
