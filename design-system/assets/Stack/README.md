# Stack

These are monochrome tech logos for the TechMarquee, each set with its name in IBM Plex Sans 500 at 18px. The files are single-ink `ink-tertiary` (#8f857d), which is their resting colour. On hover they turn `ink-primary`. Never use their brand colours.

The logos are Python, FastAPI, PostgreSQL, SQLAlchemy, LangGraph, scikit-learn, TypeScript, React, Tailwind CSS, Supabase and GitHub Actions. They are the product marks of their owners, used here only to name the tools.
