# SectionLabel

The section header: a mono uppercase eyebrow, a light display title whose second line is dimmed, and an optional note or action on the right.

You provide `eyebrow` (one word, e.g. “Work”), `title`, an optional `dim` second line, `note` or `action` (a node, usually a secondary Button), `id` and `level`.

- Titles are set light at 400 and split in two: the claim in `ink-primary`, then the qualifier in `ink-secondary` (“Featured projects / & shipped systems”).
- Use an ampersand, not “and”, to start the dimmed line.
